What it does

Six things. Done properly.

Every feature exists because it removes friction. Nothing was added to fill a checklist.

— 01

Incremental builds

A compiler that understands what changed. Only recompiles stale sources, caches the rest. Large projects build in seconds, not minutes.

— 02

Plugin runtime

Extend the IDE without restarting it. Add menus, toolbar buttons, editor actions, and lifecycle hooks through a stable, documented API.

— 03

Dependency manager

Resolve libraries, bundle classpaths, and produce JARs from one interface. No external build tool required — though you can bring one if you like.

— 04

Sign & verify

Cryptographically sign builds. Verify artifacts. Manage trusted publishers. Security that fits in the workflow instead of interrupting it.

— 05

Light & dark themes

Two themes. Both carefully tuned for long sessions. No neon, no gimmicks — just legible type and calm contrast.

— 06

Native file tree

A project explorer that behaves like your operating system's. System icons, sensible context actions, and navigation that doesn't surprise you.

Philosophy

Software should feel like a tool, not a product.

JEFB was built on a simple idea: the best developer tools disappear. They start fast, stay fast, and never ask for more than they need. No accounts. No telemetry. No updater that phones home at midnight.

Speed as a feature

Startup under 400ms. Builds in seconds. The editor never waits for you.

Transparent by default

Every action is logged. Every config is a plain file. Nothing is hidden.

Offline first

Works without the internet. No license checks. No remote anything.

Plain-text config

XML for build, JSON for settings, Markdown for docs. Nothing proprietary.
